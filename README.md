# I Love You — Matrix Site

TikTok videosundaki karanlık terminal/matrix havasından ilham alan, mevcut romantik siteden bağımsız ayrı bir mini site.

## Özellikler

- Siyah ve sisli arka plan
- Dikey akan `I LOVE YOU` karakterleri
- Ortada büyük `LOVE / YOU` ekranı
- Ekrana dokununca farklı mesajlara geçiş
- Hafif film greni, ışık ve ripple dokunma efekti
- Mobil öncelikli, tek klasörden çalışır
- `prefers-reduced-motion` desteği

## Çalıştırma

`index.html` dosyasını doğrudan açabilir veya klasörde şu komutu çalıştırabilirsin:

```bash
python -m http.server 5600
```

Ardından `http://localhost:5600` adresini aç.

Bu proje, masaüstündeki `Aşkım, Bir Barışalım mı?` klasöründeki mevcut siteye dokunmaz.
